# BridgeLabz SIPP Training 2026

## Overview

This repository contains Java practice projects, algorithm solutions, and data structure exercises completed as part of the BridgeLabz SIPP Training program for 2026.

The collection includes:
- Data structures and collections practice
- Algorithm and problem-solving exercises
- Sorting, searching, and recursion examples
- Scenario-based Java projects and use cases
- Database and SQL resources

## Repository Structure

- `BinarySearch/` - Binary search patterns including first/last occurrences, matrix search, peak element, and rotation point problems.
- `Class_Practice/` - Examples of Java collections and framework usage such as `ArrayList`, `HashMap`, `LinkedList`, `PriorityQueue`, `TreeMap`, and more.
- `Collection_Framework/` - Scenario-based applications using collection classes, including traffic monitoring, attendance tracking, parking systems, and mission management.
- `DBMS/` - SQL query practice and database join examples.
- `DivideAndConquer_Sorting_Answers/` - Merge sort, quick sort, and related divide-and-conquer solutions for practical scenarios.
- `gcr-codebase/` - General Java coding practice with categories for arrays, control flow, exception handling, file I/O, methods, recursion, and strings.
- `Generics/` - Java generic programming examples and practice problems.
- `leet-code-codebase/` - LeetCode-style algorithm solutions for common interview problems.
- `LinkedList/` - Linked list implementation and practice utilities.
- `OOPS Practice/` - Object-oriented programming exercises exploring classes, encapsulation, inheritance, interfaces, and polymorphism.
- `scenario_based/` - Real-world simulation examples like BMI tracker, coffee shop, election system, metro management, and parking lot app.
- `Sorting_Answers_Java/` - Sorting algorithm exercises focusing on bubble sort and ranking problems.
- `Stack/` - Stack-related examples and algorithm practice.
- `TwoPointersAndSlidingWindow/` - Problems solved using two-pointer and sliding window techniques.

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or later
- A Java IDE or text editor

### Running Code

Each folder contains standalone Java classes. To run a file:

1. Open the project in your Java IDE.
2. Locate the desired `.java` file.
3. Compile and run the class with a `main` method.

Alternatively, from the command line:

```bash
cd "c:\Users\priya\OneDrive\Desktop\BridgeLabz-SIPP-Training-2026"
javac <path-to-file>.java
java <ClassName>
```
